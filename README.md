# Sales Data Analysis & Dashboard

## 📊 Project Overview

This project analyzes 500 sales transactions using Microsoft Excel 2010.

The objective of the project is to analyze sales performance, identify top-performing products and regions, and create an interactive dashboard for business insights.

## 🛠️ Tools & Technologies

- Microsoft Excel 2010
- Excel Formulas
- PivotTables
- PivotCharts
- Data Analysis
- Dashboard Creation

## 📁 Dataset

The dataset contains 500 sales transactions with information such as:

- Order Date
- Customer
- Category
- Product
- Region
- City
- Quantity
- Unit Price
- Discount
- Gross Sales
- Discount Amount
- Net Sales
- Payment Mode
- Salesperson
- Year

## 📈 Analysis Performed

The project analyzes:

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Sales by Category
- Sales by Region
- Top 5 Products by Sales
- Salesperson Performance

## 🔍 Key Business Insights

- Total Sales: ₹1,08,34,871.50
- Total Orders: 500
- Total Quantity Sold: 1,546
- Average Order Value: ₹21,669.74
- Top Category: Electronics
- Top Region: South
- Top Product: Laptop
- Top Salesperson: Arjun T

## 📊 Dashboard

The final dashboard contains:

- KPI summary
- Sales by Category
- Sales by Region
- Top 5 Products by Sales
- Salesperson Performance
